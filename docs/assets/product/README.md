Only real camera photographs, real captures, and captures of the running application belong here. Simulator media must say `demo` or `simulated` in its filename and caption.

Do not commit empty placeholder images or generated product photography.

## Capture rules

- Strip EXIF location and device-owner metadata.
- Remove serial numbers, Wi-Fi names, tokens, and private Roll details.
- Get consent from every recognisable person.
- Keep originals outside the repository; commit an appropriately sized derivative.
- State whether a result came from D4 hardware, KINO Twin, or the Studio simulator.
- Preserve aspect ratio. Do not stretch logos or UI captures.
