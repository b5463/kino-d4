# KINO Design System

## 1. Non-negotiable direction

KINO must **not** look like generic modern AI-generated SaaS.

Avoid:
- giant rounded cards;
- huge whitespace;
- gradient blobs;
- glassmorphism;
- fintech/startup dashboard look;
- oversized headings;
- generic pill UI;
- one-outline-icon-library-everywhere;
- Instagram clone behavior for Roll.

## 2. KINO Studio reference mood

Studio should feel like authentic excellent software from roughly **2003–2007**:
- MSN Messenger era;
- Windows XP utilities;
- camera companion software installed from CD;
- MiniDV capture utilities;
- old media managers;
- hardware setup tools;
- early Japanese/European digital-camera utilities;
- Winamp-era personality.

Modern usability underneath, period personality on top.

Do not make it parody or pixel-art cosplay.

## 3. Studio layout

Prefer:
- classic application shell;
- toolbar;
- compact left navigation/sidebar;
- tab strips;
- split panes;
- status bar;
- utility dialogs;
- grouped property panels;
- compact tables;
- inspectors.

Avoid endless independent cards.

## 4. Density

Moderately dense.

Users should see real device data and many useful controls without click-maze hiding.

## 5. Surfaces

Use:
- cool greys;
- pale blue utility fills;
- subtle beige/grey content wells;
- selected-tab blue;
- thin borders;
- restrained 1px highlight/shadow;
- subtle period-authentic gradients where appropriate.

Avoid:
- glass blur;
- neon;
- cyberpunk;
- heavy chrome;
- contemporary soft-card aesthetic.

## 6. Controls

Buttons can have slight tactile/beveled treatment.

Use:
- compact heights;
- obvious pressed/disabled states;
- connected tabs;
- utilitarian sliders;
- classic progress bars;
- readable labels.

Firmware progress example:

```text
Updating KINO

CAM1  █████████████ 100%
CAM2  █████████░░░   74%
CAM3
CAM4
MAIN

Do not disconnect USB.
```

## 7. Icons

Prefer small 16/20/24px icon families inspired by old utility software:
- device;
- camera;
- flash;
- SD;
- network;
- folder;
- update;
- calibration.

Slightly quirky is okay.

Avoid oversized generic line icons and emoji.

## 8. Typography

Primary:
- compact UI sans.

Secondary technical:
- narrow/mono sans.

Use normal UI sizes.
Avoid giant display typography.

## 9. Status language

Use visible status lamps:

```text
● READY
● CONNECTED
○ OFFLINE
▲ WARNING
× ERROR
```

Labels:
- CAM1 READY;
- SD OK;
- FLASH ARMED;
- 3 PENDING;
- USB CONNECTED.

## 10. KINO Roll visual direction

Roll shares the family but is simpler and more social.

Reference:
- early web photo albums;
- mid-2000s photo-sharing sites;
- digital camera galleries;
- compact framed thumbnails;
- small glossy buttons;
- modest gradients;
- photo counters;
- compact tabs.

Do not clone Instagram/TikTok.

Roll is an album/live stream, not a social network.

## 11. Roll guest example

```text
KINO ROLL
Friday House Party               LIVE

47 photos   14 Aug 2026

[wiggle] [wiggle] [quad]
[wiggle] [shot]   [wiggle]

Newest first
```

Mobile usability remains modern:
- touch-friendly;
- responsive;
- fast;
- accessible.

## 12. Branding

Family:
- KINO master wordmark;
- KINO D4;
- KINO Studio;
- KINO Roll.

D4 label = hardware model designation.
Studio label = compact technical software utility designation.
Roll label = companion gallery designation.

Sublabels never overpower KINO.

## 13. Hardware relationship

Hardware visual direction:
- future clear acrylic case;
- visible electronics;
- silver/graphite/black mark;
- exposed screws;
- handmade but intentional.

Studio can echo:
- brushed-silver accents sparingly;
- cool grey hardware panels;
- subtle blue utility accent.

Do not turn Studio into chrome skeuomorphism.

## 14. Motion

Studio:
- restrained;
- fast utility transitions;
- clear progress.

Roll:
- wiggle animation is hero;
- UI motion stays secondary.

Avoid bouncy SaaS microinteractions.

## 15. Accessibility

Period vibe must not damage accessibility.

Require:
- keyboard navigation;
- visible focus;
- semantic controls;
- good contrast;
- scalable text;
- reduced motion;
- screen-reader status announcements.

## 16. Anti-AI-slop checklist

Reject design if:
- it could be any AI startup dashboard;
- every panel is a rounded card;
- there is huge empty space;
- it uses giant gradient hero areas;
- Studio resembles Notion/Linear/Stripe;
- Roll resembles Instagram;
- status is hidden in decorative UI.

Accept when:
- it feels like real camera software;
- data density is useful;
- controls are compact;
- hardware status is obvious;
- nostalgia comes from structure/details rather than fake-retro decoration.
