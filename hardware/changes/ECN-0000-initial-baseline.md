## Problem

The D4 hardware facts existed across product specifications, twin source notes, and implementation plans without one versioned build package.

## Change

Established the D4-V1 revision, a 0.1.0 prototype design package, the BOM, logical wiring, assembly order, acceptance sheet, artifact manifest, and ECN process.

## Evidence

Values were consolidated from the maintained hardware reference and structured component manifest. Unmeasured dimensions, GPIO assignments, CAD, PCB source, and physical acceptance remain explicitly open.

## Compatibility

This notice creates the baseline. It changes no released physical unit.

## Decision

Accepted as the first traceable hardware source state. A physical release remains blocked until the D4-V1 acceptance record passes.
